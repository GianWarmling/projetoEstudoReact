# Loja de Blusas Femininas - Frontend

Frontend da aplicação Loja de Blusas Femininas desenvolvido com React e Vite.

## Tecnologias Utilizadas

- React
- Vite
- React Router DOM
- JavaScript
- CSS

## Funcionalidades

Atualmente o projeto possui:

- Página inicial com listagem de produtos
- Página de detalhes do produto
- Página Sobre
- Página Contato
- Cadastro de produtos
- Edição de produtos
- Exclusão de produtos
- Consumo de API REST

## Como Executar

Instalar as dependências:

```bash
npm install
```

Executar o projeto:

```bash
npm run dev
```

A aplicação estará disponível em:

```text
http://localhost:5173
```
